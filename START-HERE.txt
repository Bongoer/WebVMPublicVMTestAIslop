WEBVM XFCE FOR GITHUB PAGES

WHAT THIS CREATES

Each website visitor gets a separate Linux virtual machine running XFCE inside
their own browser. Visitors start from the same clean image, but their changes
aren't shared with other visitors.

This doesn't create one shared desktop that everybody controls together.
GitHub Pages is static hosting, so a truly shared machine would require a
separate server.

NO CHATGPT GITHUB CONNECTION IS NEEDED.

FASTEST INSTALLATION: GITHUB CODESPACES

1. In your normal browser, open:
   https://github.com/leaningtech/webvm

2. Press "Fork" and create a fork in your GitHub account.

3. Open your fork.

4. Press:
   Code > Codespaces > Create codespace on main

5. In the Codespace, upload this ZIP into the repository's top folder.

6. Open the Codespace terminal and run:

   unzip -o webvm-xfce-github-pages.zip -d .
   rm webvm-xfce-github-pages.zip
   git add .
   git commit -m "Add XFCE browser VM"
   git push

7. In the GitHub repository website, open:
   Settings > Pages

8. Set "Source" to:
   GitHub Actions

9. Open:
   Actions > Build and deploy XFCE WebVM > Run workflow

10. Keep the defaults and press the green "Run workflow" button.

11. When it finishes, open:
    Settings > Pages

    GitHub will show the website address.

The site root opens the XFCE machine. Every visitor receives an independent VM.

LOGIN DETAILS INSIDE THE VM

Normal user:
  username: user
  password: webvm

Administrator:
  username: root
  password: root

NETWORK ACCESS

Open WebVM's Networking panel and connect through Tailscale.

Basic TCP programs such as curl, wget and SSH can use that connection.
Public internet access needs a Tailscale exit node. The ping command isn't
expected to work because WebVM doesn't provide ICMP networking.

CODESPACES NOTE

Codespaces is only used to edit and upload the repository. Website visitors
don't consume your Codespaces hours. Their VMs run locally in their browsers.

MOBILE PERFORMANCE

XFCE is much heavier than WebVM's normal terminal and its i3 desktop.
On a phone, close other large browser tabs before starting it.
